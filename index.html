10. Database Design — Logistics Company (Oracle SQL / 3NF)

Designed a complete relational database for TransNacional Express S.A.S., a national cargo transportation company. Built the full design lifecycle: conceptual model (Entity-Relationship diagram with cardinalities), logical model in Oracle SQL Developer Data Modeler, and physical DDL script in Oracle SQL. The schema includes 10 tables covering clients (natural persons and companies via specialization), packages, branches, employees, vehicles, shipments and deliveries. Normalized to Third Normal Form (3NF) with proper primary keys, foreign keys, CHECK constraints, UNIQUE constraints and resolved N:M relationships through junction tables.

📂 Featured projects

1. Urban Routes – Manual Testing, Test Cases, Equivalence Classes

Manual QA project focused on validating the Urban Routes application using structured test design techniques. I identified and documented equivalence classes and boundary values to reduce the number of test cases while keeping full functional coverage. I created clear, reproducible test cases (inputs, steps, expected results, pass/fail). I also built a flowchart and a mind map to describe how Urban Routes works and its main user paths, improving communication and requirement traceability.

2. Urban Routes – UI/UX Testing, Error Reporting

Quality assurance project focused on validating the user interface and user experience of the Urban Routes app. I designed and documented manual test cases for each visible feature (“Reserve” button, “Car reserved” window, cancellations, field validations) and for the UI/UX layer. Tests were executed in different screen resolutions using Chrome and Firefox DevTools to verify responsive behavior. All issues were logged in Jira with steps to reproduce, expected vs actual result, and evidence, to ensure usability, visual consistency and functional stability across browsers.

3. Urban Grocers – API Testing

Service testing project focused on validating GraphQL, REST and SOAP APIs using Postman as the main tool. I applied equivalence classes, functional testing and boundary testing to ensure APIs handled valid, invalid and missing data correctly. I verified status codes, response structure and error handling. All defects were reported in Jira with clear reproduction steps and expected vs actual result. This project extends the manual QA practices from Urban Routes to the API layer.
